# Stretch


Stretch is a WearOS port of [Molly](https://github.com/mollyim/mollyim-android), the hardened version of [Signal](https://github.com/signalapp/Signal-Android) for Android, a fast simple yet secure messaging app by [Signal Foundation](https://signal.org).

## Feedback

- [Submit bugs and feature requests](https://github.com/ellyellyelly/stretchim-android/issues) on GitHub

## Reproducible Builds

Stretch inherits reproducible build support from Molly. Anyone can run the build process to reproduce the same APK as the original release.

Please check the guide in Molly's [reproducible-builds](https://github.com/mollyim/mollyim-android/blob/master/reproducible-builds) directory.
